## Phase Goal

> ROADMAP Phase 2 Goal (verbatim): "Participants add cards to any quadrant, and every connected browser on the session sees them appear live, relayed by the Python server from Supabase Realtime."

The goal is not written as a user story. As in every Phase 1 plan, it is quoted verbatim and no story is invented (run `/gsd-mvp-phase 2` to rewrite it as one).

This plan is the phase **tracer**: one real path through every layer the phase touches.

browser A (NiceGUI add field) -> SessionService.add_card -> Repository.insert_card -> hosted Supabase `cards` -> Postgres Changes event -> RealtimeHub._on_card -> registry keyed by workspace_id -> CanvasView.apply_card -> browser B.

Task 1 proves that path live. Task 2 adds the read half of the same slice (a reopened canvas shows every stored card) and the offline proofs the expansion plans build on. Plans 02-02 to 02-05 grow out from this slice:
- 02-02 authoring rules: validation messages, author gate edge cases, DB author constraint
- 02-03 live fidelity: edits, moves, deletes and DB-direct changes projected live, latency proof
- 02-04 browser reconnect and server restart recovery
- 02-05 Realtime connection recovery

## Scope Note: Task 1 file count (kept, with reasons)

Task 1 lists 11 files, above the 5-file guideline. It stays one task because the count comes from the tracer shape, not from extra scope:
- **One file per layer the slice crosses:** models (domain types), repository (data), sessions (service), deps and main (wiring), hub (Realtime), canvas_view and canvas_page (UI). Add the three files its end-to-end verify cannot run without: tests/conftest.py (the live hub fixture), tests/ui/fakes.py (the Services shape changes, so the 96 existing offline tests would break without it) and the live test itself.
- **Most edits are a few lines:** deps gains one field, main one constructor argument, models one class, conftest one fixture.
- **Splitting would break the tracer rule.** Any split produces a horizontal "hub only" or "UI only" task with no runnable end-to-end proof. Phase 1's tracer (01-02) made the same call.
- **Everything optional is elsewhere:** the snapshot read is Task 2; text validation, error messages, the double-submit guard and author edge cases are 02-02; UPDATE/DELETE projection is 02-03; recovery is 02-04 and 02-05.

## Flagged assumptions (edge probe and design)

- **SYNC-02 (edge probe: unclassified, left unresolved):** the probe could not classify this requirement into an edge category. Its behavior is covered by the truths and the two SYNC-02 prohibitions above, not by an edge row.
- **A-01 Realtime timestamp format:** realtime-py delivers `record` values as JSON. This plan assumes `created_at`/`updated_at` strings parse with pydantic `datetime`. The live test is the ground truth: if parsing fails, add a `field_validator(..., mode="before")` on CardView that normalizes the observed format, and quote one observed raw value in the SUMMARY.
- **A-02 Card time zone (planner's discretion, reversible):** NiceGUI is server-driven and the browser time zone is unknown to the server. Card times use the server process's local zone (the app runs locally for v1) as `HH:MM`, and the tooltip carries the full timestamp with its zone name.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> NiceGUI server | Untrusted card text enters through the add field; the server decides author, quadrant and session |
| Supabase Realtime -> Python server | Postgres Changes payloads are parsed and fanned out to browser views |
| Python server -> Supabase (PostgREST) | The server holds the secret key; the DB CHECKs and composite FK still enforce card shape and placement |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-SC | Tampering | dependency installs | high | mitigate | This plan installs no packages; pyproject.toml and uv.lock stay unchanged. Any new dependency needs a fresh blocking-human legitimacy checkpoint |
| T-02-01 | Information Disclosure | RealtimeHub fan-out (one global channel) | high | mitigate | `_on_card` routes only to listeners registered under the row's workspace_id. test_event_for_another_session_is_not_rendered proves another session's card never renders |
